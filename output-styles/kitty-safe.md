---
name: Kitty Safe
description: Output formatting for Kitty terminal (no blockquotes/italics)
keep-coding-instructions: true
---

- NEVER use blockquotes (> syntax) - renders with unreadable white background
- NEVER use italic (*text* or _text_) or bold italic (***text***)
- Use **bold** and `inline code` for emphasis instead
- Code blocks, lists, bold, and inline code render fine
- For quoting: use **Bold label:** "quoted text" format instead of blockquotes
